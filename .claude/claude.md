fsprinter es una app para crear un servicio de impresión ESC/POS y Zebra/ZPL para los plugins Tickets y Etiquetas de FS, funciona en todas las plataformas ios (iphone, ipad y mac), windows, linux y android, no necesita versión web. Conecta con impresoras ya sea por red, usb o bluetooth para imprimir los tickets o etiquetas.
